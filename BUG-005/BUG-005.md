# BUG-005: GuidanceGo 1.0.0 Manual Authorization [Appointment Access Control]: Appointment details accessible by unauthorized users via shared URL

**[Summary]** Users can access another user's appointment details using a direct appointment URL. Example: https://guidancego-dev.vercel.app/appointments/fca21a68-2de4-454d-9f0e-d5ad57e6a78e A second user can view, edit, or cancel another user's appointment.

**[Precondition]** 
* Software version: 1.0.0 
* Software configuration: Next.js, Supabase, Tailwind CSS 
* Hardware specifications: Standard Web Browser 
* Network configuration: Standard Internet Connection

**[Steps to reproduce]**
1. Log in to the GuidanceGo application as User A.
2. Create an appointment and copy the direct URL (e.g., /appointments/fca21a68...).
3. Log out and log in as User B (an unauthorized student).
4. Paste the direct URL of User A's appointment into the browser.
5. Observe that User B can view and interact with the appointment.

**[Actual results]** Unauthorized users can access and potentially modify another user's appointment. This is a critical security vulnerability.

**[Expected results]** Only the appointment owner and the assigned counselor should be able to access the appointment details. Unauthorized users should be blocked with a 403 error or redirected.
