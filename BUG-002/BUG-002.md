GuidanceGo 1.0.0 Manual Dashboard [Messaging]: Dashboard message count does not match actual messages

[Summary]
Dashboard displays 3 unread messages while the Messages page contains no messages.

[Precondition]
Software version: 1.0.0
Software configuration: Next.js, Supabase, Tailwind CSS, Google OAuth
Hardware specifications: Standard Web Browser
Network configuration: Standard Internet Connection

[Steps to reproduce]
1. Log in to the GuidanceGo application.
2. Navigate to the Dashboard.
3. Observe the unread message count displaying '3'.
4. Click on the Messages section/page.
5. Observe that there are actually zero messages present.

[Actual results]
The Dashboard displays an incorrect unread message count of 3, while the actual Messages page shows no messages.

[Expected results]
The message count on the Dashboard should accurately reflect the actual number of unread messages in the user's inbox (which is 0).
