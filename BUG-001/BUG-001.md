# BUG-001: GuidanceGo 1.0.0 Manual Appointment Booking [Notifications]: Successful booking notification reappears after page refresh

**[Summary]** After successfully booking an appointment, refreshing the page repeatedly causes the success notification to reappear even though the booking action has already been completed.

**[Precondition]** 
* Software version: 1.0.0 
* Software configuration: Next.js, Supabase, Tailwind CSS, Google OAuth, Google Calendar, Google Meet 
* Hardware specifications: Standard Web Browser 
* Network configuration: Standard Internet Connection

**[Steps to reproduce]**
1. Log in to the GuidanceGo application.
2. Proceed to book a counseling appointment and complete the process successfully.
3. Observe the success notification appearing on the screen.
4. Refresh the page.
5. Notice that the same success notification appears again.

**[Actual results]** The success notification for booking an appointment is displayed every time the user refreshes the page after the initial successful booking.

**[Expected results]** The success notification should only appear once immediately after the appointment is successfully booked, and it should not reappear upon subsequent page refreshes.
