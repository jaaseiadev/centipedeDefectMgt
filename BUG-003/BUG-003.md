# BUG-003: GuidanceGo 1.0.0 Manual Authentication [Route Protection]: Authenticated users can access login and sign-up pages

**[Summary]** Users who are already authenticated can still access /login and /sign-up routes.

**[Precondition]** 
* Software version: 1.0.0 
* Software configuration: Next.js, Supabase, Tailwind CSS, Google OAuth 
* Hardware specifications: Standard Web Browser 
* Network configuration: Standard Internet Connection

**[Steps to reproduce]**
1. Log in to the GuidanceGo application successfully.
2. Manually enter the /login URL into the browser address bar.
3. Observe that the login page is displayed.
4. Manually enter the /sign-up URL into the browser address bar.
5. Observe that the sign-up page is displayed.

**[Actual results]** Login and sign-up pages remain accessible to users who are already authenticated.

**[Expected results]** Redirect authenticated users to the dashboard when they attempt to access /login or /sign-up.
