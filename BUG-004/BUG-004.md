# BUG-004: GuidanceGo 1.0.0 Manual Authorization [Role-Based Access Control]: Student account accessing counselor-only settings results in blank page

**[Summary]** Counselor settings routes: /settings?category=schedule /settings?category=integrations can be manually accessed by student accounts. Instead of showing an access denied page or redirect, the application displays a blank screen.

**[Precondition]** 
* Software version: 1.0.0 
* Software configuration: Next.js, Supabase, Tailwind CSS 
* Hardware specifications: Standard Web Browser 
* Network configuration: Standard Internet Connection

**[Steps to reproduce]**
1. Log in to the GuidanceGo application using a Student account.
2. Manually enter the URL /settings?category=schedule into the browser address bar.
3. Observe the blank page.
4. Manually enter the URL /settings?category=integrations into the browser address bar.
5. Observe the blank page.

**[Actual results]** A blank page is displayed when a student account accesses counselor-only settings routes.

**[Expected results]** The application should display a 403 page, an access denied message, or redirect the student back to an authorized page (e.g., Dashboard).
